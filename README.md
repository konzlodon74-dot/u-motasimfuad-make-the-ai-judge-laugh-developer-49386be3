A tiny Python program (stdlib only) that prints one funny single-line excuse a developer gives when code breaks in production, and writes the same line to `/output/entry.txt`. The excuse is delivered in the developer's own voice: the code is fine, production is just running the build from before the fix because the deploy failed silently — and silence is its love language. A concrete little scene with a real turn, no wasted setup, and no explanation of its own joke.

Run it with `python3 main.py`. It prints exactly one line (145 characters) and writes it to `/output/entry.txt`, well within the 200-character gate.
